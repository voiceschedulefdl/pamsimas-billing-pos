# PAMSIMAS Billing POS

Aplikasi manajemen tagihan air PAMSIMAS/PDAM yang ringan dan profesional.

## Tentang Aplikasi

PAMSIMAS Billing POS adalah aplikasi Android yang dirancang khusus untuk pengelola PAMSIMAS, PDAM desa, dan perusahaan air bersih skala kecil-menengah. Aplikasi ini membantu mencatat meteran air, menghitung tagihan otomatis, mencetak struk, dan mengirim laporan ke pelanggan via WhatsApp.

## Fitur Utama

- Foto Meteran: Ambil bukti foto saat catat meter, otomatis terkirim ke WhatsApp pelanggan bersama struk
- Cetak Struk: Support printer thermal Bluetooth untuk cetak struk di lapangan
- Laporan Cepat: Rekap tagihan lunas/hutang bisa di-share ke grup WhatsApp
- Backup dan Restore: Data aman dalam format JSON, bisa dipindahkan antar perangkat
- Dinamis: Nama PAMSIMAS dan nomor WhatsApp layanan bisa diatur sendiri di layar awal
- Aktivasi PRO: Buka fitur lengkap dengan sistem aktivasi yang aman

## Cara Install

1. Download file APK dari halaman Releases
2. Buka file di HP Android
3. Izinkan instalasi dari sumber tidak dikenal jika diminta
4. Buka aplikasi dan isi nama PAMSIMAS serta nomor WhatsApp di layar awal
5. Mulai catat meteran pelanggan

## Cara Penggunaan

1. Buka aplikasi, isi nama PAMSIMAS dan nomor WhatsApp layanan
2. Tambah data pelanggan di menu Pelanggan
3. Di menu Meter, pilih periode tagihan (bulan/tahun)
4. Pilih pelanggan, masukkan angka meteran baru
5. Ambil foto meteran dengan tombol kamera
6. Simpan tagihan (Hutang atau Lunas)
7. Klik CETAK untuk mengirim struk + foto ke WhatsApp pelanggan

## Persyaratan Sistem

- Android 5.0 (Lollipop) atau lebih baru
- Ruang penyimpanan minimal 20 MB
- Kamera (untuk fitur foto meteran)
- Bluetooth (opsional, untuk cetak struk)
